# Coco daily publication target

- Target: **666 verified public publications per Asia/Kolkata calendar day**.
- Count only a publication whose public URL is reachable and whose published content/readback evidence is stored.
- Drafts, attempts, blocked submissions, duplicates, and pending moderation do not count.
- Preserve historical daily records; reset the daily counter at 00:00 Asia/Kolkata.
- Discovery may be worldwide and multilingual. Submission remains restricted to sites whose current rules explicitly permit the specific automated submission. Respect robots.txt, site terms, per-domain limits, and stop on CAPTCHA, login barriers, rate limits, or unclear permission.

This target declaration does not itself guarantee throughput or change the runtime's capacity. The current workflow runs in bounded GitHub Actions jobs; scheduled jobs can be delayed. Verify the daily ledger and public evidence before reporting progress.
